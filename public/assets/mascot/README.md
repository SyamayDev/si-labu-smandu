# Daftar Asset Maskot SI LABU

Semua file disimpan di folder ini dalam format WebP transparan. Asset yang belum tersedia akan disembunyikan otomatis, jadi layout tetap rapi.

| Nama file                | Pose yang perlu dibuat                                                      | Dipakai di                             | Rekomendasi  |
| ------------------------ | --------------------------------------------------------------------------- | -------------------------------------- | ------------ |
| `mascot.webp`            | Berdiri heroik, satu tangan terbuka menyapa, ekspresi percaya diri          | Hero landing page                      | 800 x 900 px |
| `mascot-step-01.webp`    | Memegang buku atau tangan di dada, ekspresi siap bercerita                  | Langkah 01: Ceritakan                  | 360 x 360 px |
| `mascot-step-02.webp`    | Mengangkat amplop atau memegang tombol kirim, ekspresi lega                 | Langkah 02: Kirim                      | 360 x 360 px |
| `mascot-step-03.webp`    | Memegang ponsel dengan gelembung chat WhatsApp                              | Langkah 03: Ditangani                  | 360 x 360 px |
| `mascot-step-04.webp`    | Jempol atau pose tenang dengan tanda centang                                | Langkah 04: Selesai                    | 360 x 360 px |
| `mascot-supportive.webp` | Duduk/berlutut kecil dengan tangan terbuka, ekspresi hangat dan menenangkan | FAQ dan trust section                  | 500 x 500 px |
| `mascot-success.webp`    | Mengangkat dua tangan kecil atau memegang bintang, ekspresi lega            | Success screen laporan                 | 500 x 500 px |
| `mascot-small.webp`      | Bust/head only, senyum ringan                                               | Avatar, footer, atau empty state admin | 240 x 240 px |

## Arahan visual

- Pertahankan helm oranye, tubuh hijau, dan kostum biru tua yang sudah menjadi identitas maskot.
- Gunakan background transparan, tanpa teks, tanpa logo sekolah tambahan, dan tanpa watermark.
- Jangan membuat pose terlalu dramatis; SI LABU harus terasa aman, ramah, dan dapat dipercaya.
- Sisakan ruang 5-8% di sekeliling karakter agar tidak terpotong pada mobile.
- Jangan membuat semua pose sekaligus jika belum perlu. Prioritas: `mascot.webp`, lalu empat `mascot-step-*.webp`.
